# DictationBot

Telegram-бот для ежедневной тренировки дикции: каждый день присылает случайный
сет на ≈14 минут, ведёт стрик и раз в 14 дней устраивает замер по фиксированному
контрольному тексту. Стек: Python 3.11+, aiogram 3, SQLite (aiosqlite), APScheduler 3.

## Запуск

```bash
uv venv .venv && uv pip install -e ".[dev]"   # или: python -m venv .venv && .venv/bin/pip install -e ".[dev]"
cp .env.example .env                          # вписать BOT_TOKEN и OWNER_ID
.venv/bin/python -m bot
```

Схема БД создаётся автоматически при старте (отдельно: `python -m bot.db`). Миграции —
`migrations/NNN_*.sql`, применённая версия хранится в `PRAGMA user_version`.

Тесты: `.venv/bin/python -m pytest`

## Структура

| Путь | Что там |
|---|---|
| `bot/domain/` | Логика чистыми функциями: сборка сета, стрик, замеры. Покрыта тестами |
| `bot/content/` | Pydantic-схемы и загрузка JSON-контента (валидация при старте) |
| `bot/db/` | Подключение, миграции, репозиторий |
| `bot/scheduler/` | Ежедневное напоминание и полночная проверка стрика (APScheduler) |
| `bot/handlers/` | Команды и кнопки |
| `bot/texts.py` | Все тексты сообщений |
| `data/` | Контентные пулы (сейчас заглушки) |

## Контент

Всё в `data/`. Формат проверяется при старте: ошибка в JSON остановит бот с указанием файла.

- **`articulation_exercises.json`** — объект `{"_readme": ..., "exercises": [...]}`, упражнение:
  `{id, name, muscle_group, instructions, mode, reps, duration_sec, caution}`.
  `muscle_group`: `jaw` | `lips` | `cheeks` | `tongue` — в каждой должно быть хотя бы одно.
  `mode`: `reps` — дискретные повторы (`reps` обязателен, в сообщении «15 повторений, ~45 сек»)
  или `continuous` — одно слитное действие (`reps: null`, `duration_sec` обязателен, «выполняй 60 сек»).
  `caution` — необязательное предупреждение, показывается всегда.
- **`tongue_twisters.json`** — объект `{"_readme": ..., "twisters": [{id, text}, ...]}`, один общий пул.
- **`reading_texts.json`** — объект `{"_readme": ..., "texts": [{id, text}, ...]}`, отрывки ~100-150 слов.
- **`control_text.json`** — `{id, text}`, один текст для всех замеров.

Новые элементы просто дописываются в файлы, id должны быть уникальными.
- **`stickers.json`** (необязательный) — file_id стикеров по событиям: `completed`, `milestone`
  (стрик 3/7/14/21/30/50/100/200/365 дней), `measurement_saved`, `streak_lost`. Бот берёт случайный
  из списка, пустой список — без стикера. Чтобы узнать file_id, отправь стикер боту вне диалога —
  он ответит его file_id. После правки файла бота нужно перезапустить.

## Правила

- **Сет**: по одному случайному упражнению из каждой группы мышц (не то, что было в прошлом
  выполненном сете, если в группе есть альтернатива) + абзац для чтения с пробкой + скороговорка.
  Последний блок — пересказ абзаца своими словами, чтобы тренировать чёткость в свободной речи.
  Сет фиксирован на весь день — напоминание, `/today` и кнопка видят одно и то же.
  Упражнения всегда в порядке челюсть → губы → щёки → язык, после них — фиксированная фраза
  «тпру-у-у». Инструкции к упражнениям скрыты, кнопка «Показать инструкции 📖» / «Свернуть 🔼»
  перерисовывает то же сообщение (сет хранится в callback_data кнопки). Абзац и скороговорка
  показываются всегда целиком.
- **Абзацы и скороговорки не повторяются**: берутся только из ещё не выпадавших в выполненных
  сетах. Когда пул исчерпан — начинается новый круг (без повтора последнего элемента подряд).
- **Стрик**: «Выполнил ✅» → +1. В полночь, если вчера сет не выполнен, стрик обнуляется.
  Больше ничего не сбрасывается.
- **Замер**: первый — сразу после регистрации, дальше раз в 14 календарных дней от последнего.
  Контрольный текст всегда один, плюс 2-3 случайные скороговорки (по возможности не из прошлого
  замера). Два голосовых — максимально чётко и расслабленно — и необязательная заметка.

## Доступ

Бот закрытый: отвечает только пользователям из белого списка (таблица `allowed_users`),
владелец (`OWNER_ID`) в нём всегда. Когда незнакомый человек пишет боту, владельцу приходит
запрос с кнопками «✅ Разрешить» / «🚫 Отклонить» (один раз за запуск бота), человек получает
ответ, что запрос отправлен. Команды владельца (видны только ему в меню):

- `/users` — кто имеет доступ и их стрики;
- `/allow ID` — дать доступ вручную (ID можно узнать у @userinfobot);
- `/deny ID` — забрать доступ. Напоминания прекращаются, данные остаются: `/allow` вернёт всё как было.

## Деплой (systemd)

```ini
# /etc/systemd/system/diction-bot.service
[Unit]
Description=Diction bot
After=network-online.target

[Service]
WorkingDirectory=/opt/DictationBot
ExecStart=/opt/DictationBot/.venv/bin/python -m bot
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

`systemctl enable --now diction-bot`. Бэкап — копия файла `var/bot.db`.

## Ограничения

- Незаконченный замер или смена времени хранятся в памяти: после рестарта бота замер нужно
  начать заново через `/measure`.
- Часовой пояс (`TIMEZONE`) один на всех пользователей.
